# README FOR STUDENT

## Manual Steps Required
You must perform the following actions manually and take screenshots to save in the `evidence/` folder:
1. **Jira Import**: Import `jira/epics.csv` and `jira/stories.csv` into your Jira board. Move stories across the board (TO DO -> IN PROGRESS -> DONE) to generate the burndown chart. (You can also use the generated `burndown.png` generated by the sprint_sim.py script if permitted).
2. **GitHub Branch Protection**: Go to your GitHub repository settings, enable branch protection on `main`, requiring PR reviews and status checks to pass before merging. Take a screenshot.
3. **GitHub Actions**: Push the code to GitHub and take a screenshot of the passing CI workflow (pytest, bandit, pip-audit).
4. **Minikube Deployment**: Run the following commands and screenshot their outputs:
   - `minikube start`
   - `kubectl create secret generic iems-secrets --from-literal=jwt_secret=supersecret`
   - `kubectl apply -f k8s/deployment.yaml`
   - `kubectl apply -f k8s/service.yaml`
   - `kubectl apply -f k8s/networkpolicy.yaml`
   - `kubectl get pods,svc,networkpolicy`
5. **Draw.io / UML Diagrams**: Some diagrams need to be manually laid out in draw.io. You can use the generated mermaid models in `docs/diagrams/` as a reference. Use Mermaid-CLI (`npx @mermaid-js/mermaid-cli -i <file.mmd> -o <file.png>`) to generate PNGs.

## Placeholders to Replace
- In `report/IEMS_Report.md`:
  - `[Your Name]` -> Replace with your actual name.
  - `[Your Roll No.]` -> Replace with your roll number.
  - `[Date]` -> Replace with today's date.
- In `iems/jira/stories.csv`: Update the Sprint numbers if required by your Jira instance.
